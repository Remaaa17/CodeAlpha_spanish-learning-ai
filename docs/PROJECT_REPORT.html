Task 2: AI Chatbot

NLP-Powered Spanish Learning Assistant COMPLETED

Intelligent chatbot using Groq AI (Llama 3.3 70B) with NLTK preprocessing and TF-IDF FAQ matching for accurate Spanish learning guidance.

Features Implemented

  • Groq AI integration (Llama 3.3 70B)
  • NLTK natural language processing
  • TF-IDF similarity matching
  • 20+ pre-programmed Spanish learning FAQs

AI Architecture

User Question ↓ NLTK Preprocessing (tokenize, lemmatize) ↓ TF-IDF Similarity Check (20 FAQs) ↓ Match Found? → Return FAQ Answer ↓ (No match) Groq AI (Llama 3.3 70B) → Generate Response

Task 4: Object Detection & Tracking

YOLOv8 + Deep SORT Visual Learning System COMPLETED

Real-time object detection with multi-object tracking, integrated with Spanish translation for innovative visual vocabulary learning.

Core Requirements Met

  • Real-time video input (webcam + file upload)
  • OpenCV integration for frame processing
  • Pre-trained model: YOLOv8 Nano (COCO 80 classes)
  • Bounding boxes with confidence scores
  • Deep SORT multi-object tracking
  • Persistent tracking IDs across frames
  • Real-time display with labels

BONUS Features (Beyond Requirements)

  • Automatic Spanish translation of detected objects
  • One-click flashcard generation from detected vocabulary
  • Web-based interface (no desktop app)
  • All image formats supported (JPG, PNG, GIF, BMP, WebP)
  • Session statistics and vocabulary tracking

Deep SORT Algorithm

Detection Pipeline: 1. YOLOv8 detects objects → bounding boxes 2. Kalman Filter predicts next position 3. Hungarian Algorithm matches detections to tracks 4. Track Management: create/update/delete 5. Spanish Translation via MyMemory API 6. Display with ID, label, translation, confidence

Technical Stack

YOLOv8 Deep SORT OpenCV Kalman Filter Hungarian Algorithm NumPy PyTorch
